# Osaka Trip 2026 🇯🇵

## เป้าหมายของทริป
1. 🍁 **ใบไม้เปลี่ยนสี** — พัก **Arashiyama (Kyoto) 2 คืน** เดินเท้าชมป่าไผ่/แม่น้ำ/ใบไม้แดง + Ginkakuji (Philosopher's Path)
2. 🎢 **Universal Studios Japan** — Super Nintendo World (จัดวันอังคาร 1 ธ.ค. เลี่ยงคนวันหยุด)
3. 🦌 **Nara** ให้อาหารกวาง + วัดพระใหญ่
4. 🥩 **Steak อร่อย** — Kobe beef teppanyaki มื้อกลางวัน: Steak Land (คุ้มสุด ¥3,500–4,880) หรือ Mouriya (พรีเมียม ~¥9,800+)

## เช็คลิสต์ก่อนเดินทาง

### เอกสาร / ออนไลน์ (ทำล่วงหน้า)
- [ ] หนังสือเดินทางทุกคน มีอายุเหลือ 6 เดือนขึ้นไป (เด็กต้องมีพาสปอร์ตของตัวเอง) — พาสปอร์ตไทย **ยกเว้นวีซ่า 15 วัน** (เช็คประกาศล่าสุดก่อนเดินทาง)
- [ ] กรอก **Visit Japan Web** (QR สำหรับ immigration + customs) ทำได้ก่อนบินไม่นาน
- [ ] ประกันการเดินทาง (ครอบครัว + เด็ก)
- [ ] ซื้อ **ตั๋ว USJ** + Express Pass (ต้องระบุวันที่ — เปิดขายล่วงหน้า ~2 เดือน, ซื้อเร็วที่สุด)
- [ ] eSIM ญี่ปุ่น (Ubigi / Airalo / Klook) หรือ Pocket WiFi
- [ ] จองโรงแรม (ยกเลิกได้ยิ่งดี รอเคาะแผนก่อน)

### เงิน / สื่อสาร
- [ ] แลกเงินเยน (ประเมินรวมในไฟล์ itinerary) + บัตรเครดิตสำรอง
- [ ] เพิ่ม **Suica/ICOCA** ลง Apple Wallet บน iPhone ใช้ขึ้นรถไฟได้เลย

### สำหรับเด็ก 5 ขวบ
- [ ] เสื้อกันหนาว/เสื้อชั้นในกันหนาว ถุงมือ หมวกไหมพรม (5–14°C หนาวกว่าเชียงใหม่มาก)
- [ ] รถเข็นเด็กพับได้ (ญี่ปุ่นระบบรถไฟรองรับดี) — เด็ก 5 ขวบเดินเยอะมาก วันละ 10–15k ก้าว
- [ ] ยาประจำตัว/ยาลดไข้เด็ก พลาสเตอร์
- [ ] ขนม/ของว่างที่ลูกชอบ กันเบื่อบนเครื่องและรอคิว

### อื่น ๆ
- [ ] ปลั๊กไฟญี่ปุ่นแบบแฉก 2 ขา (Type A) เหมือนไทย แต่ไฟ 100V — เครื่องชาร์จมือถือใช้ได้ปกติ
