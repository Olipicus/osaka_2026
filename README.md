# Osaka Trip 2026 🇯🇵

## เป้าหมายของทริป
1. 🍁 **ใบไม้เปลี่ยนสี** — พัก**ติด Kyoto Station 2 คืน** (Hotel Vischio ✅): อา. เที่ยวเมือง **วัดน้ำใส + Gion + วัดทอง** · จ. **รถไฟไป Arashiyama** (ป่าไผ่ + เรือ Hozugawa ล่องหุบเขาใบแดง) แล้วย้ายเข้า Universal City
2. 🎢 **Universal Studios Japan** — Super Nintendo World (จัดวันอังคาร 1 ธ.ค. เลี่ยงคนวันหยุด)
3. 🦌 **Nara** ให้อาหารกวาง + วัดพระใหญ่
4. 🥩 **Steak อร่อย** — Kobe beef teppanyaki มื้อกลางวัน: Steak Land (คุ้มสุด ¥3,500–4,880) หรือ Mouriya (พรีเมียม ~¥9,800+)

## เช็คลิสต์ก่อนเดินทาง

### เอกสาร / ออนไลน์ (ทำล่วงหน้า)
- [ ] หนังสือเดินทางทุกคน มีอายุเหลือ 6 เดือนขึ้นไป (เด็กต้องมีพาสปอร์ตของตัวเอง) — พาสปอร์ตไทย **ยกเว้นวีซ่า 15 วัน** (เช็คประกาศล่าสุดก่อนเดินทาง)
- [ ] กรอก **Visit Japan Web** (QR สำหรับ immigration + customs) ทำได้ก่อนบินไม่นาน
- [ ] ประกันการเดินทาง (ครอบครัว + เด็ก)
- [ ] ซื้อ **ตั๋ว USJ** + Express Pass (ต้องระบุวันที่ — เปิดขายล่วงหน้า ~2 เดือน, ซื้อเร็วที่สุด)
- [ ] จอง **เรือ Hozugawa รอบ ~13:30 จ. 30 พ.ย.** (~¥16,500 ครอบครัว — hozugawakudari.jp / โทร +81-771-22-5846 / Klook · ก่อนจองเช็ค Torokko ออนไลน์รอบจันทร์ก่อน)
- [ ] ซื้อ **HARUKA One-way Ticket** (KIX→Kyoto วันถึง) — ¥2,700/ผู้ใหญ่ ซื้อ**ออนไลน์ก่อนถึงญี่ปุ่นเท่านั้น** (ราคาใหม่ตั้งแต่ 1 พ.ย. 2026, จองได้แล้ว — ดู transport.md)
- [ ] eSIM ญี่ปุ่น (Ubigi / Airalo / Klook) หรือ Pocket WiFi
- [x] ✅ จองโรงแรมครบ 4 แห่ง (Hotel Vischio Kyoto · Universal Port · Citadines Namba · OMO Kansai Airport — กลับมาใช้ Vischio 14 พ.ย.) — เหลือ: ยืนยันห้อง Triple นับเด็ก 5 ขวบ + เก็บอีเมลยืนยันทุกที่พัก
